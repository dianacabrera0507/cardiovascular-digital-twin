# Workflow 02: identificabilidad

1. Fijar modelo y parámetros candidatos.
2. Evaluar identificabilidad estructural cuando sea posible.
3. Simular escenarios conocidos.
4. Realizar múltiples inicializaciones.
5. Explorar perfiles de costo y correlaciones.
6. Añadir ruido, faltantes y submuestreo.
7. Definir parámetros reportables y no reportables.
