# Workflow 01: auditoría de datos

1. Registrar versión y autorización.
2. Construir manifiesto de archivos y registros.
3. Enumerar canales, unidades, frecuencias y duración.
4. Cuantificar simultaneidad de señales.
5. Verificar enlace con información clínica.
6. Aplicar reglas de calidad preespecificadas.
7. Producir diagrama de flujo y tabla de cobertura.
8. No entrenar modelos antes de cerrar este informe.
