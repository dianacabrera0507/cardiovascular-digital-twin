# Gobernanza y seguridad de datos

- Acceder únicamente mediante credenciales y acuerdos válidos.
- No incluir datos clínicos en el ZIP, repositorio, incidencias o documentación.
- Mantener `data/raw` inmutable y con acceso restringido.
- Separar código, configuraciones, datos y resultados.
- No registrar identificadores sensibles en logs.
- No utilizar servicios externos sin autorización expresa del acuerdo de datos.
- Registrar versión, fecha de extracción, consulta y checksum cuando esté permitido.
- Revisar manualmente todos los artefactos antes de publicarlos.
