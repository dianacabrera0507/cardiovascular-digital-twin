# Lista de comprobación para reporte

- [ ] Versión y acceso de los datos verificados.
- [ ] Cohorte reproducible y diagrama de flujo.
- [ ] Definiciones de señales, ondas y mediciones intermitentes separadas.
- [ ] Protocolo temporal y prevención de fugas documentados.
- [ ] Identificabilidad evaluada antes de interpretación fisiológica.
- [ ] Incertidumbre reportada.
- [ ] Evaluación fuera de muestra.
- [ ] Comparadores con información equivalente.
- [ ] Discriminación y calibración reportadas.
- [ ] Resultados negativos y limitaciones incluidos.
- [ ] Código, semillas y configuraciones preservados.
- [ ] No se afirma utilidad clínica sin validación suficiente.
